枝图 / Branch — macOS 安装说明

1. 打开 DMG，将“枝图.app”拖到 Applications（应用程序）。
   如果下载的是 ZIP，解压后将“枝图.app”拖到“应用程序”。
2. 从“应用程序”打开枝图。桌面应用无需 Python、账号或联网。
3. 本版本使用 ad-hoc 签名，未做 Apple Developer ID 签名和公证。
   首次打开如提示无法验证开发者，请在确认下载来源后，打开：
   系统设置 → 隐私与安全性 → 仍要打开。
   无需关闭系统的安全保护。
   Apple 官方说明：https://support.apple.com/102445

系统：macOS 14.0 或以上。当前公开安装包为 Apple Silicon（M 系列）arm64。
实测环境：Apple Silicon / macOS 26.4.1；其他系统版本尚未实机验证。

操作：Tab 新增子节点；Enter 新增同级；空白画布右键新增主节点。
空白处左键拖动框选；Shift / ⌘ 追加选择；拖动选中节点可一起移动。
按住空格拖动或使用滚轮平移画布。
完整工程：使用“导出 → 完整工程副本 (.branch)”，可发给同样安装枝图的朋友。
图片嵌入工程，不必另外发送原图。多主节点工程需要 0.2.1 或更新版本。
本机工程目录：~/Library/Application Support/枝图/

应用更新：先退出枝图，再替换“应用程序”里的应用；本机工程单独存储。
卸载应用不会自动删除本机工程。
